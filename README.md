# Shahid Yousuf Blog Labs

Runnable code for the hands-on tutorials on [shahidyousuf.dev](https://shahidyousuf.dev/blog/). Each folder belongs to one article and is named after its URL, so `reencrypt-vault-transit-data-python/` goes with `shahidyousuf.dev/blog/reencrypt-vault-transit-data-python/`.

| Lab | Article |
|---|---|
| [reencrypt-vault-transit-data-python](reencrypt-vault-transit-data-python/) | [How to Move Vault-Encrypted Data to New Keys Safely](https://shahidyousuf.dev/blog/reencrypt-vault-transit-data-python/) |

Every lab runs locally in Docker with throwaway data and dev-only credentials. None of it is production configuration.

Found a bug or something out of date? Open an issue.
